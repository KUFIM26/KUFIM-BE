## 1. 요약

v0.4는 v0.3을 **사용자 모바일 웹과 부스 운영자 MVP로 축소**한 재편본이다. 혼잡도 관제(STG), 다국어(I18N), 총괄 관리자, 인프라성 기능(WebSocket, Redis, Rate Limit 등)은 삭제되거나 후속 범위로 이동했다.
그 결과 **기능 ID 체계가 재번호화되어 같은 ID가 다른 기능을 가리키게** 되었고, 삭제된 항목 중 상당수가 v0.4의 변경 사항 표(8장)에 기록되지 않았다.

| 구분 | v0.3 | v0.4 |
|---|---|---|
| 사용자 화면 | U-01~U-14 (14개) | U-00~U-12 (13개) |
| 관리자 화면 | A-01~A-16 (16개, 총괄 중심) | A-01~A-03 (부스 운영자) + 후속 12개 |
| 기능 수 | 86개 (COM/PRG/STG/WAI/MAP/ADM/I18N) | 약 69개 (COM/HOME/PRG/MAP/WAI/NOT/ADM, 후속 9개 포함) |
| 기능표 컬럼 | 기능ID·기능명·설명·**FR**·화면·**담당**·우선 | 기능ID·기능명·설명·화면·우선 (FR·담당 제거) |
| 개발 주차 배정 | 있음 (4~14주차) | 없음 |
| 관리자 권한 코드 | `SUPER_ADMIN` / `BOOTH_ADMIN` | 없음 |

## 6. 정합성 이슈

### 6.1 추적성

1. **기능 ID 충돌**: 5.2의 굵은 항목처럼 같은 ID가 다른 기능을 가리킨다. v0.3은 "기능 ID는 API 명세서와 1:1 대응"을 원칙으로 했으므로 API 명세서·코드·커밋에서 ID를 참조할 때 버전을 명시하지 않으면 혼동된다.
2. **화면 ID 충돌**: A-01~A-03이 v0.3(로그인/현황판/호출 콘솔)과 v0.4(부스 대시보드/설정/취소 모달)에서 다른 화면이다. v0.4 2.3절은 "기존 화면 ID"라는 열 제목으로 구분하지만 같은 문서 안에서 같은 ID가 두 의미로 쓰인다.
3. **FR 컬럼 제거**: 요구사항 명세서(FR)로 거슬러 추적할 수 없다.

| 운영자 인증 부재 | 부스 운영 대시보드(A-01)는 MVP인데 로그인·계정 관리·권한 제어는 후속 또는 삭제. 부스 운영자가 담당 부스에만 접근하는 방법이 정의되지 않음 |

### 6.3 v0.4 8장(변경 사항 표)의 누락·오기

- **누락**: 혼잡도 관제 삭제, 편의시설 삭제, 예상 대기시간 산출 방식 변경, 부스 카테고리 체계 변경, 기술 기반 기능 삭제, 문자 부가 기능 삭제, 개발 주차 배정 삭제
- **오기**: "v0.3 앱 내 스캐너 여부 모호"라고 했으나 v0.3 2.1절에 "앱 내 스캐너를 구현하지 않으며, QR은 U-07로 직접 연결되는 딥링크 URL을 담는다"라고 명시되어 있음

### 6.4 누락된 연결

- U-12 전체 메뉴가 연결하는 "전체 프로그램", "부스 목록"에 화면 ID가 없다.
- 기존 A-07 편의시설 관리, A-08 공연 관리, A-10 지도 관리가 2.3 후속 화면 목록에 없다. A-08과 A-10은 F-ADM-16에 포함된 것으로 보이나 편의시설은 문서 전체에서 사라졌다.

### 6.5 코드 정의

- 부스 분류 코드에 `ALL`이 포함되어 있다. 필터 값이므로 DB enum에서는 제외해야 한다.
- 6.1 상태 다이어그램에 `EXPIRED`와 운영자 취소 전이(`CALLED → CANCELED`)가 그려져 있지 않다.
- `WAITING` 전이 주체가 v0.3 "—"에서 v0.4 "시스템"으로 바뀌었다 (의미 차이는 없음).
