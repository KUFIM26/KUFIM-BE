# 후속 연결 및 운영 확인

API 명세서 v0.4의 활성 REST 경로는 백엔드에 추가했습니다. 다음 항목은 외부 서비스·FE 또는 운영 정책이 정해져야 완료됩니다.

1. **FE 연결:** 브라우저 UUID 토큰 저장과 `/waitings/me` 자동 복원, QR의 `/w/{boothCode}` 페이지, 관리자 세션·CSRF 요청, 대기표 상태·재호출·입장 UI를 실제 API에 연결합니다.
2. **SMS 공급자:** 현재 호출은 앱 알림을 만들고 `smsStatus=NOT_CONFIGURED` 이력을 남깁니다. 공급자 계정, 발신 번호, 하루 한도와 오류 매핑을 확정한 뒤 실제 발송기를 연결합니다.
3. **운영 DB 확인:** MySQL 8.0.19 이상과 Redis에서 Flyway V1~V5, 세션 저장, 동시 접수, 자동 취소를 검증합니다. 기존 DB에 `party_size > 6` 행이 있다면 V2 적용 전에 정리합니다.
4. **개인정보 보유 기간:** `/admin/privacy/purge`는 입력한 시각 이전의 종료된 표를 익명화합니다. 실제 자동 파기 주기와 보유 기간, 기존 공지 읽음 기록에 남은 토큰의 처리 정책을 정합니다.
5. **실시간 확장:** 현재 단일 서버 STOMP 브로커를 사용합니다. 여러 서버에서 운영할 때 공유 브로커와 세션 권한·재연결 동작을 검증합니다.
6. **명세의 보류 기능:** 혼잡도, 다국어, 이미지 업로드, 일괄 QR PDF, 분석 CSV, 개별 문자 재발송 등은 [보류 목록](deferred.md)에 남아 있습니다.
