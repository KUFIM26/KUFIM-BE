주간 미팅 일정 조율 및 결정
2. 프로젝트 주차 진행 내용
원활한 공동 개발을 위해 첫 주차는 개발 환경을 구축했습니다.
먼저 OGRE와 Vulkan을 설치했습니다. 이때 작업자 간 상이한 로컬 환경에서도 동일한
조건으로 프로젝트가 빌드될 수 있도록 CMake를 도입하여 CMakeLists.txt 기반의 일
관된 환경을 마련했습니다.
다만 OGRE 엔진의 용량이 크기 때문에 GitHub에 직접 업로드를 할 수 없었고, 각 인
원들이 개별로 엔진을 설치할 때 발생하는 경로 오류를 해결하고자 패키지 관리자인
vcpkg를 도입했습니다.
GitHub Organization과 전용 Repository를 개설했습니다. .gitignore를 설정해 스크립트
외 불필요한 파일의 공유를 차단함으로써 용량 문제를 해결하고 독립적인 환경에서의
빌드가 원활히 이루어질 수 있도록 하였습니다. 또한 glfw, glm 등의 공용 라이브러리
를 Repository 내에서 설치되도록 구성하여 팀원 간 라이브러리 버전 불일치로 인한
충돌을 방지했습니다.
3. 프로젝트 주차 진행 결과
OGRE 엔진 및 Vulkan API 설치를 완료했습니다.
CMakeLists.txt 작성 및 vcpkg 연동 세팅을 마무리했습니다.
오프라인 미팅 및 회의 시기를 결정했습니다.
화, 금, 일 (각 6시간): 주요 기술 논의 및 연동 사항 점검 등 이슈 트래킹을 수행할 예
정입니다.
수요일: 지도교수님과 주간 미팅을 진행하여 프로젝트 피드백을 수렴하기로 했습니다.
목요일 (8시간): 주간 이슈 트래킹 내용을 종합 및 각자 진행 사항에 대한 중간 보고를
진행하고, 주간 진행 보고서 작성 및 차주 개발 계획을 수립하기로 했습니다.
이수민: 통합된 공동 작업 환경 하에서 Vulkan 기본 렌더링 파이프라인을 구축했습니
다.
정근녕: CMake 및 vcpkg를 활용하여 OGRE 및 Vulkan 기반의 안정적인 공동 작업 환
경 및 빌드 시스템 인프라 구축을 완료했습니다.
한승현: 통합된 공동 작업 환경 하에서 Vulkan Compute Pipeline을 구축했습니다.
4. 기타(문제점, 해결방법, 자기평가 등)
효율적인 프로젝트 진행을 위해 역할을 분담하여 병렬적인 개발 프로세스를 채택하기
로 하였습니다.
이수민은 고퀄리티 비주얼 구현을 위한 렌더링 파이프라인 구축 및 연구를 맡았습니
다.
정근녕은 엔진의 성능 최적화를 위한 OGRE 엔진과 Vulkan API 간의 연동 구조 설계
를 맡았습니다.
한승현은 물리 시뮬레이션을 위한 컴퓨트 파이프라인 구축 및 연구의 역할을 맡았습니
다.
차주 주간 보고서부터는 위 분담 체계에 따라 각 파트별 내용이 나뉘어 작성될 예정입
니다.
